Backup & restore

Your records are stored locally on this device. Export a backup regularly, especially before clearing browser data or changing phones.

Privacy & storage

No account or cloud sync is required. The app stores information in this browser's local storage. Anyone with access to this browser profile may be able to open the app. Browser storage can be cleared by device settings.

Install on Android
  1. Host these app files on a secure static website (HTTPS).
  2. Open the website in Chrome on your Android phone.
  3. Open Chrome's menu and choose “Install app” or “Add to Home screen”.
  4. Confirm installation. Open My Life Tracker from your home screen.

Service-worker offline features require HTTPS (or localhost during development). This package is a Progressive Web App, not a native APK.
